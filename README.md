## 🚀 Featured Project

### [WriteAI](https://writeai-teal.vercel.app) — Full-stack AI Writing Platform

> A production-deployed AI writing app built on real distributed-systems decisions, not glue code.

**Stack:** React 19 · Node.js · Express 5 · MongoDB Atlas · Redis · BullMQ · Gemini 2.5 Flash · Vercel + Render

- **Chunk-based document storage** — only modified sections are persisted on autosave, replacing naive full-document writes
- **Per-chunk version conflict detection** with UI resolution modal for concurrent edits
- **Streaming AI** (8 actions) over Server-Sent Events with Redis locks preventing duplicate calls
- **Background export workers** (BullMQ) for non-blocking PDF/DOCX generation with retries
- **Multi-tier rate limiting** + daily AI quotas with graceful degradation when Redis is unavailable
- **Dual-path JWT auth** — debugged & fixed iOS Safari ITP cross-site cookie failure on cross-origin deployment

**→** [Live Demo](https://writeai-teal.vercel.app) · [GitHub](https://github.com/Animesh-kumar23/WriteAI)
